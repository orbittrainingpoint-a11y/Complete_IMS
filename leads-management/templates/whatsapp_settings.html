Setup Guide
  1. Create/select a Meta Business app with the WhatsApp product added
  2. Fill in Phone Number ID, WABA ID, and a permanent System User Access Token here, then Save
  3. Copy the Webhook Callback URL and Verify Token shown below and paste them into Meta App Dashboard → WhatsApp → Configuration → Webhook
  4. Subscribe to the messages field so delivery statuses and replies (including STOP opt-outs) reach the CRM
  5. Click Test Connection to confirm the token/phone number are valid before creating campaigns
The access token and app secret are sensitive — treat them like passwords. This page is admin-only.
Marketing messages require a Meta-approved message template. Manage templates and their approval status from the Messages page.
