Setup Guide
Website (Elementor Pro)
  1. Add an integration below, save it
  2. Copy its webhook URL
  3. In Elementor: edit the form → Actions After Submit → add "Webhook"
  4. Paste the URL into the Webhook action's URL field
Facebook / Instagram Lead Ads
  1. Create (or use) a Meta Developer App and connect your Page as its admin/tester
  2. Add an integration below with your Page ID and a Page Access Token (needs leads_retrieval permission)
  3. In the Meta App Dashboard, add the Webhooks product, subscribe the Page to the leadgen field
  4. Paste the Callback URL and Verify Token shown below into that subscription
Page Access Tokens are sensitive — treat them like a password. This page is admin-only.
