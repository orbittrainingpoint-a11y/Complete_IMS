Primavera P6 Course

Learn advanced planning and enterprise project control with Primavera P6.
ORBITTraining Center

Course Description

This course delves into Primavera P6 for professional project control. Master WBS creation, activity sequencing, and baseline management. Projects include resource leveling, critical-path analysis, and S-curve generation for application in large-scale construction, oil, and gas projects.

Master the P6 interface
Create project schedules
Allocate resources effectively
Track progress updates
Perform earned-value analysis
Generate advanced reports
Optimize multi-project portfolios
